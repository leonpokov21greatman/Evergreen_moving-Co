Privacy Policy

Last updated: November 7, 2026

Evergreen Moving Co. is a demo website made as a practice project. It is not a real company.

Information we collect

None. The quote form on this site is a demo: what you type stays in your own browser and is never sent, stored, or shared. The phone number and email address shown on the site are examples that don't reach anyone.

This website does not use cookies, analytics, or advertising trackers. The font and icons are stored on this website, so loading a page does not contact other companies.

This site is hosted on GitHub Pages. GitHub may keep basic technical logs, such as IP addresses, when pages are visited, as described in GitHub's own privacy statement.

Changes to this policy
