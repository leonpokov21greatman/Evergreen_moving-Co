# Evergreen Moving Co. (demo website)

A practice project: a website for a made-up Baltimore moving company. **It is not a real business.**
The phone number, email address, and quote form are examples only, and the form doesn't send anything.

**Live site:** https://leonpokov21greatman.github.io/Evergreen_moving-Co/

## What's in it

- 9 pages: home, 6 service pages, a privacy policy, and a 404 page
- Plain HTML, CSS, and JavaScript, with no frameworks and no outside scripts
- Works on phones, tablets, and desktops, and without JavaScript
- Search-engine extras: page titles and descriptions, structured data, and link-preview images.
  Pages are marked `noindex`, so search engines don't list a company that isn't real.

## Files

- `index.html`: home page, with the services, FAQ, and demo quote form
- `*-moving.html`, `packing-services.html`, `storage.html`, `specialty-items.html`: service pages
- `style.css`: all the styling (colors are set at the top)
- `script.js`: phone menu, menu highlighting, and the demo form
- `fonts/`: the Outfit font (SIL Open Font License)
- Icons are from [Lucide](https://lucide.dev) (ISC license)
